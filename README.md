# visualsbyginger.

Beispielseite für visualsbyginger. – Auto-, Motorrad-, Tier-, Porträt- und Produktfotografie aus Aschaffenburg und Frankfurt.

Diese Version dient nur als Vorschau. Die endgültige Seite läuft später als WordPress-Theme bei Hostinger unter visualsbyginger.de.
Das Kontaktformular zeigt hier nur einen Hinweis; echte Anfragen verschickt erst die WordPress-Version.

## Online stellen mit GitHub Pages

1. Auf github.com anmelden › oben rechts „+“ › „New repository“.
2. Name: `visualsbyginger` › „Public“ › „Create repository“.
3. „uploading an existing file“ anklicken und den **Inhalt** dieses Ordners hineinziehen
   (index.html, style.css, site.js, og-image.jpg, README.md und den Ordner `bilder`) › „Commit changes“.
4. Settings › Pages › Source: „Deploy from a branch“ › Branch: `main`, Ordner `/ (root)` › Save.
5. Nach 1–2 Minuten ist die Seite erreichbar unter `https://DEIN-NAME.github.io/visualsbyginger/`.

Die Seite ist für Suchmaschinen gesperrt (noindex), damit Google später nur die echte Seite findet.
